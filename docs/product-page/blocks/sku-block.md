## **SKU block**

<SectionMeta version="v1.0.0" availability="Product page" />

The SKU block displays the SKU of the currently selected variant on the product page. It updates automatically when the customer switches variants. If a variant has no SKU set in the Shopify admin, the block renders empty.

This block has no configurable settings.

## **How to add the block**

1. In the Shopify theme editor, open the **Product page** template.
2. In the **Main Product** section, click **Add block → SKU**.
3. Only one SKU block is allowed per section (limit: 1).
