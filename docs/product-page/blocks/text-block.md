## **Text block**

<SectionMeta version="v1.0.0" availability="Product page" />

The Text block displays a custom text section on the product page, with an optional heading. It can be used to add supplementary product information such as a description, usage notes, or any additional content that sits outside the main product description field.

## **Settings**

![](/img/docs/text-pdp-block.png)

- **Heading:** Enter an optional heading displayed above the text content.
- **Tab content:** Enter the text content displayed in this block.
- **Tab content from page:** Select a Shopify page to use as the source of the text content instead of the manually entered text above.
