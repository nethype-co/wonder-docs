## Custom Liquid block

<SectionMeta version="v1.0.0" availability="Product page" />

The Custom Liquid block allows you to add custom app snippets or other Liquid code directly within the product page layout, enabling advanced customizations and integrations without modifying theme files.

## Main Settings

* **Custom Liquid**: Enter any Liquid code or app snippet to render custom content in this position on the product page.
