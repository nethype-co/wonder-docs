## What is the Testimonial: Marquee section?

<SectionMeta version="v2.3.0" />

The Testimonial: Marquee section lets you display customer reviews in a horizontally auto-scrolling banner — making it ideal for showcasing testimonials, quotes, or recommendations in a dynamic and eye-catching way.

## Main settings

**General**

* **Headline**: Set the title for the section using the built-in rich text editor (supports heading styles, bold, italic, links, and lists).
* **Animation direction**: Choose the scrolling direction — To left or To right.
* **Marquee mode speed**: Set the animation speed from three options — Slow, Normal, or Fast.

**Large screen version**

* **Card width desktop**: Set the width of a single testimonial card on desktop.
* **Gap**: Set the spacing between cards on the desktop.

**Mobile version**

* **Card width mobile**: Set the width of a single testimonial card on mobile devices.
* **Gap**: Set the spacing between cards on mobile devices.

**Colors**

All color fields default to Transparent, which inherits values from your global theme settings.

* **Text color**: Set the color of the text within the section.
* **Background color**: Set the background color of the entire section.
* **Testimonial background color**: Set the background color of the scrolling marquee strip.
* **Card heading color**: Set the color of the heading on each individual card.
* **Card author color**: Set the color of the author text on each card.

**Section spacing**

* **Distance from the top**: Adjust the spacing above the section.
* **Distance from the bottom**: Adjust the spacing below the section.

## Customize testimonial block

Each **Testimonial** block represents a single customer review card displayed within the marquee.

**Block settings**

* **Icon**: Choose the star rating displayed on the card — select from a dropdown.
* **Heading**: Set the title or short headline for the testimonial using the built-in rich text editor (supports bold, italic, and links).
* **Text**: Enter the full review content using the rich text editor.
* **Author**: Add the name or attribution of the reviewer using the rich text editor.
* **Author image**: Upload or select an image to display alongside the author's name.
* **Adjust image height for desktop**: Set the display height of the author image on desktop.
* **Adjust image height for mobile**: Set the display height of the author image on mobile devices.
