# Does Wonder have…?

Short answers to common "is there a setting for…" questions.

:::tip Something looks broken?
Ask an [AI assistant connected to Wonder](/ai-agents/setup). It checks the known issues of your Wonder version and tells you which update fixes them.
:::

## A favicon setting?

Yes. In the theme editor, open **Theme settings → Favicon** and choose a **Favicon image**. It's scaled down to 32 × 32 px, so use a simple, square image.

## A sticky add-to-cart bar? How do I hide it?

Yes, it's on by default on mobile. See [Sticky buy button](/product-page/product-information#sticky-buy-button) for all the options and how to turn it off.

## A place for my own CSS that survives updates?

Yes: **Theme settings → Custom CSS**, and a **Custom CSS** field in each section. See [Custom CSS](/theme-settings/custom-css).

## Google Analytics or tracking pixels in the theme settings?

No, and you don't need them there. Tracking is set up in Shopify itself, so it keeps working when you change or update your theme:

- **Google Analytics 4 and Google Ads:** install Shopify's **Google & YouTube** app.
- **Meta, TikTok, Pinterest and similar:** install the platform's official Shopify app.
- **Other pixels:** Shopify admin → **Settings → Customer events → Add custom pixel**.

## What happens to my changes when I update Wonder?

Settings and content are kept; code edits aren't. See [Updating Wonder: what's kept and what isn't](/getting-started/basics/updating-wonder).
