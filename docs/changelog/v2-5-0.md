# v2.5.0 - August 07, 2026

One of our biggest updates yet. This release introduces powerful new sections, a completely redesigned product card, a refreshed Velour preset, new merchandising features, AI-ready enhancements, and dozens of UX, performance, and quality-of-life improvements throughout the theme.

## Highlights

- **Redesigned Product Cards** — swipeable image galleries, color and product siblings, Quick Buy with size picker, a new Pro card style, and improved accessibility
- **Velour Preset Refresh** — completely redesigned for modern fashion brands with a stronger focus on storytelling, premium visuals, and mobile-first CRO
- **5 New Sections** including Quiz, Bundle Builder, Shoppable Buy All, Grid View with Modal, and Transparent Slideshow Hero
- **New Transparent Header Layout** with a centered logo and animated mega menu
- **New Merchandising Features** — discount percentage badges, estimated delivery, price inside the Add to Cart button, Instant Checkout, and product ratings
- **Ultra-Wide Display Support** up to 3840px

## Added

- **New Sections:**
  - Quiz — a guided, multi-step product finder that recommends products based on the shopper's answers
  - Bundle Builder — lets shoppers assemble their own multi-product bundle and add the whole set to cart in one step
  - Shoppable Buy All — showcases a curated set of products with per-item quick-add and a single "add all to cart" action
  - Grid View with Modal — a collection grid where clicking an item opens its details in a pop-up modal instead of leaving the page
  - Transparent Slideshow Hero — a slideshow hero built for the transparent header, so the menu overlays the first slide edge-to-edge
- **Swipeable Product Card Galleries** with keyboard navigation
- **Color and Product Siblings** on product cards
- **Pro Product Card** style
- **Quick Buy with Size Picker**
- **Transparent Header (Logo Center)** layout with animated mega menu
- **Native Video Controls** — play, pause, mute, and full controls across all video sections
- **Discount Percentage Badges**
- **Estimated Delivery Block**
- **Instant Checkout** option
- **Price Inside the Add to Cart Button**
- **Product Ratings** in Search, Product Cards, and Product Pages, with optional review count
- **Load More Pagination** for collection pages with a cumulative product counter
- **Scroll to Top Button**
- **Animated Metrics** in the Metrics Banner
- **"Us vs Them" Comparison Table** preset
- **Additional Typography Controls** and heading effects
- **Ultra-Wide Layout Support** up to 3840px

## Changed

- Refactored Product Page blocks for easier customization
- Faster hero rendering with no white flash or layout shift
- Improved product gallery loading and better LCP performance
- Sticky product gallery now remains in place while switching variants
- Updated translations and localization files
- Removed unused CSS and JavaScript for improved performance

## Fixed

- Improved transparent header and logo behavior across all layouts
- Fixed product card ratings after variant changes and multiple Pro Card layout issues
- Fixed Buy Button price display, Quick Buy layout, and mobile rendering
- Improved newsletter responsiveness and alignment
- Fixed video controls, overlays, and Grid View interactions
- Fixed blog styling and spacing issues
- Resolved JSON-LD structured data validation errors
- Improved marquee, sliders, navigation, spacing, colors, sticky behavior, and responsive layouts across multiple sections
