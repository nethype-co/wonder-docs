# v2.5.0 - August 07, 2026

One of our biggest updates yet. This release introduces powerful new sections, a completely redesigned product card, a refreshed Velour preset, new merchandising features, AI-ready enhancements, and dozens of UX, performance, and quality-of-life improvements throughout the theme.

## Highlights

- [**Redesigned Product Cards**](/guides/how-to-articles/how-to-set-up-a-product-card) — swipeable image galleries, color and product siblings, Quick Buy with size picker, a new Pro card style, and improved accessibility
- [**Velour Preset Refresh**](/getting-started/basics/installing-and-choosing-a-preset#velour) — completely redesigned for modern fashion brands with a stronger focus on storytelling, premium visuals, and mobile-first CRO
- **5 New Sections** including [Quiz](/sections/storytelling/quiz), [Bundle Builder](/sections/products/bundle-builder), [Shoppable Buy All](/sections/products/shoppable-buy-all), [Grid View with Modal](/sections/storytelling/grid-view-with-modal), and Transparent Slideshow Hero
- [**New Transparent Header Layout**](/sections/header-navigation/header/#transparent-header) with a centered logo and animated mega menu
- **New Merchandising Features** — [discount percentage badges](/theme-settings/product-badges), [estimated delivery](/product-page/blocks/estimated-delivery-block), price inside the Add to Cart button, [Instant Checkout](/product-page/blocks/buy-button-block), and [product ratings](/product-page/blocks/rating-block)
- **Ultra-Wide Display Support** up to 3840px

## Added

- **New Sections:**
  - [Quiz](/sections/storytelling/quiz) — a guided, multi-step product finder that recommends products based on the shopper's answers
  - [Bundle Builder](/sections/products/bundle-builder) — lets shoppers assemble their own multi-product bundle and add the whole set to cart in one step
  - [Shoppable Buy All](/sections/products/shoppable-buy-all) — showcases a curated set of products with per-item quick-add and a single "add all to cart" action
  - [Grid View with Modal](/sections/storytelling/grid-view-with-modal) — a collection grid where clicking an item opens its details in a pop-up modal instead of leaving the page
  - Transparent Slideshow Hero — a slideshow hero built for the transparent header, so the menu overlays the first slide edge-to-edge
- [**Swipeable Product Card Galleries**](/guides/how-to-articles/how-to-set-up-a-product-card#classic-vs-pro-at-a-glance) with keyboard navigation
- [**Color and Product Siblings**](/guides/how-to-articles/how-to-set-up-a-product-card#sibling--variation-swatches-combined-listings) on product cards
- [**Pro Product Card**](/guides/how-to-articles/how-to-set-up-a-product-card) style
- [**Quick Buy with Size Picker**](/guides/how-to-articles/how-to-set-up-a-product-card#quick-buy-picker)
- [**Transparent Header (Logo Center)**](/sections/header-navigation/header/#transparent-header) layout with animated mega menu
- [**Native Video Controls**](/sections/video/background-video) — play, pause, mute, and full controls across all video sections
- [**Discount Percentage Badges**](/theme-settings/product-badges)
- [**Estimated Delivery Block**](/product-page/blocks/estimated-delivery-block)
- [**Instant Checkout**](/product-page/blocks/buy-button-block) option
- **Price Inside the Add to Cart Button**
- [**Product Ratings**](/product-page/blocks/rating-block) in Search, Product Cards, and Product Pages, with optional review count
- **Load More Pagination** for collection pages with a cumulative product counter
- [**Scroll to Top Button**](/theme-settings/scroll-to-top)
- [**Animated Metrics**](/sections/text-forms/metrics-banner) in the Metrics Banner
- **["Us vs Them" Comparison Table](/sections/products/comparison-table)** preset
- [**Additional Typography Controls**](/theme-settings/typography) and heading effects
- **Ultra-Wide Layout Support** up to 3840px

## Changed

- Refactored Product Page blocks for easier customization
- Faster hero rendering with no white flash or layout shift
- Improved product gallery loading and better LCP performance
- Sticky product gallery now remains in place while switching variants
- Updated translations and localization files
- Removed unused CSS and JavaScript for improved performance

## Fixed

- Improved transparent header and logo behavior across all layouts
- Fixed product card ratings after variant changes and multiple Pro Card layout issues
- Fixed Buy Button price display, Quick Buy layout, and mobile rendering
- Improved newsletter responsiveness and alignment
- Fixed video controls, overlays, and Grid View interactions
- Fixed blog styling and spacing issues
- Resolved JSON-LD structured data validation errors
- Improved marquee, sliders, navigation, spacing, colors, sticky behavior, and responsive layouts across multiple sections
