# v2.3.0 - April 07, 2026

This release introduces the new **Petit Preset** — a clean, modern CRO-focused demo layout designed for product-focused storefronts. Alongside Petit, this update brings 10 new sections, subscription widget support, a sticky buy button, an expanded icon library, and improvements to accessibility, performance, and responsiveness across the entire theme.

## Highlights

- **New Preset: Petit** — CRO-focused demo layout with dedicated templates for product pages, collections, FAQ, contact, about us, and product model comparison
- **10 New Sections** including Slide-up Banner, Scrollytelling Video, Collection Navigator, Compare Products, and more
- **Subscription Widget** block on product detail pages with one-time purchase options
- **Sticky Buy Button** on desktop with variant and selling plan change support

## Added

- **New Preset: Petit**
- **New Section: Slide-up** — full-screen hero with blur overlay, text alignment controls, card blocks, and blur toggle
- **New Section: Scrollytelling Video** — scroll-driven video with image mode fallback and mobile options
- **New Section: Collection Navigator** — tabbed collection browsing with progress bar and swiper
- **New Section: Featured Collections Tabs** — tabbed collections with slider and gradient scroll
- **New Section: Compare Products / Comparison Table** — side-by-side product comparison with icons
- **New Section: Scrolling Icon with Text** — horizontal scrolling banner with dot separator
- **New Section: Metric Banner** — stats display with grid/slider modes and auto-rotate
- **New Section: Grid View with Drawer** — grid layout with expandable drawer detail
- **New Section: Collapsible Menu with Image** — expandable menu with image, video, and custom icon support
- **New Section: Testimonial Marquee** — continuous scrolling testimonials
- **Subscription Widget** block for PDP with plan ordering, price display, and one-time purchase options
- **Product Variations (Siblings)** — product image picker type for variant selection
- **Sticky Buy Button** on desktop with loading spinner and variant/selling plan change support
- **Newsletter Consent Checkbox** with custom validation message
- **43 New Icons** for food, clothing, shipping, and general purpose use cases
- **Icon Select for Feature Icons** — dropdown picker as alternative to image upload on PDP
- **Announcement Bar Text Size** — configurable font size range (80%–200%) for mobile and desktop
- **Custom Add to Cart Text** — configurable button label and info text for preorder use cases, pre-order feature support
- **Quick Buy Button Setting** — option to show below product card on desktop
- **Inventory Count Threshold** — show stock count when below a set number
- **Highlighted Menu Items** — color and icon support for all navigation link levels
- **Footer Enhancements** — separator block, image with text block, B&W social icon setting

## Changed

- **Multicolumn Section** — swiper slider support on mobile, increased max blocks to 12
- **Parallax Section** — support up to 4 images
- **Collapsible Row** — updated styling, image as icon option
- Various responsiveness and styling improvements across heading blocks, hero titles, video sections, and testimonials

## Fixes and Other Improvements

- Various styling and layout fixes across sections including animations, product gallery, variant pickers, pricing, navigation drawers, and responsive behavior
- Improved accessibility (ARIA labels, focus management, keyboard navigation)
- Performance optimizations including LCP improvements for hero media
- Rich text full-width option, collapsible blocks default open setting, and other minor section enhancements
- Updated all 5 core locales (en, de, es, fr, it) for all new features
