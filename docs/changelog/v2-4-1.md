# v2.4.1 - June 17, 2026

This release introduces Shopify's new Color Palette feature, allowing you to define your brand colors once and reuse them consistently across your entire theme.

## Highlights

- **Color Palette** — set a reusable set of named brand colors in **Theme settings → Colors → Palette**, then pick them from any color setting; change a palette color once and every place that uses it updates

## Added

- **Color Palette** — up to 20 named colors (e.g. primary, secondary, accent, background, button, border, sale, rating). Each preset (Nook, Petit, Root, Velour, Wonder) ships with a curated starter palette
