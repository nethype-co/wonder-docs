## General Settings

This page covers layout, animations, icons, search, social media, and other global settings found under **Theme Settings** in the Theme Editor.

## Layout

- **Layout width** — Set the maximum content width of your store (1400–1900px, default: 1900px).
- **Border radius** — Set the default border radius for elements like cards and images (0–30px, default: 4px).
- **Button radius** — Set the border radius for buttons (0–30px, default: 15px).

## Animations

- **Enable animations** — Turn on scroll-triggered animations throughout the theme.
- **Enable picture animations** — Turn on reveal animations for images.
- **Disable animations on mobile** — Turn off all animations on mobile devices for improved performance.

## Icon Set

The Wonder Theme includes 4 built-in icon sets. Choose the one that best matches your store's style.

- **Icon set** — Select from 4 icon style options.
- **Enable bag icon** — Show a bag icon for the cart in the header.
- **Enable lock icon** — Show a lock icon on the buy button.

### Custom Icons

Override individual header icons with your own images:

- **Menu icon** — Upload a custom icon for the mobile menu button.
- **Search icon** — Upload a custom icon for the search button.
- **Account icon** — Upload a custom icon for the account button.
- **Bag icon** — Upload a custom icon for the cart button.

## Predictive Search

- **Enable predictive search** — Show search suggestions as customers type in the search field.

### Search Content Filters

Control what content is included in predictive search results:

- **Author** — Include article author names.
- **Body** — Include product and article body content.
- **Product type** — Include product type in search results.
- **Tag** — Include product and article tags.
- **Title** — Include product and article titles.
- **Variants barcode** — Include variant barcodes.
- **Variants SKU** — Include variant SKU codes.
- **Variants title** — Include variant titles.
- **Vendor** — Include product vendor names.

## Search Behavior

- **Enable suggestions** — Show search suggestions in the search overlay.
- **Show product vendor** — Display the vendor name in search results.
- **Show product price** — Display the price in search results.

## Social Media

### Share Buttons

Enable sharing buttons on product pages:

- **Facebook** — Show a Facebook share button.
- **Twitter/X** — Show a Twitter/X share button.
- **Pinterest** — Show a Pinterest share button.

### Social Links

Add your social media profile URLs. These are displayed in the footer and other areas that show social icons.

- **Twitter/X**
- **Facebook**
- **Pinterest**
- **Instagram**
- **TikTok**
- **Tumblr**
- **Snapchat**
- **YouTube**
- **Vimeo**

## Localization

- **Show flag in localization drawer** — Display country flags next to language/country options in the localization selector.

## Currency Format

- **Show currency code** — Display the currency code (e.g. USD, EUR) alongside prices.
