## Installing the Wonder Theme & Choosing a Preset

The Wonder Theme comes with **5 preconfigured presets** — each offering a unique look and layout tailored to different store types. All presets share the same features and functionality — the only difference is the visual configuration, section arrangement, and default styling.

Choose the preset that best matches your brand, and customize it from there.

## How to Install a Preset

1. Click the **Install preset** link for the preset you want (listed above), or visit the [Wonder Theme page](https://themes.shopify.com/themes/wonder) on the Shopify Theme Store.
2. If you have already purchased the theme, click **Add latest version** or **Add new copy**.
3. If you haven't purchased yet, click **Try theme** to add it as a trial.
4. The theme will be installed in your Shopify admin with all the preset's sections, layout, and styling pre-applied.

Each preset installs a fully configured version of the Wonder Theme — you can start customizing right away.
